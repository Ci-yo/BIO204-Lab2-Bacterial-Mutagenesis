## Step-by-step guide

### 1. Prepare your computer and get the files

Use [R](https://cran.r-project.org/) (R 4.4 or later recommended).
RStudio is optional. Check `Rscript --version` in your terminal. Install [Git](https://git-scm.com/downloads) to use the commands below.
Run them in a **terminal** (PowerShell on Windows; Terminal on macOS/Linux):

```bash
git clone https://github.com/Ci-yo/BIO204-Lab2-Bacterial-Mutagenesis.git
cd BIO204-Lab2-Bacterial-Mutagenesis
```

Alternatively, use **Code → Download ZIP**, extract it, and open a terminal in
the extracted folder. All commands below start in the folder containing
`README.md`. A second run replaces the generated outputs named below.

### 2. Read the archived observations

Open [`data/plate_counts.csv`](data/plate_counts.csv). The analysis uses the
recorded `plate_id` and `colony_count` values; no new experiment is needed.
The calculation assumptions are visible in
[`scripts/calculate_mutation_frequencies.R`](scripts/calculate_mutation_frequencies.R).
Only base R is required.

### 3. Recalculate the published tables

```bash
Rscript scripts/calculate_mutation_frequencies.R
```

Expected checks include an estimated density of `2.76e+09 CFU/mL` and the
archived UV 20 s induced-frequency estimate of `3.25e-06`.

### 4. Read the outputs and validate

| Output | What to check |
|---|---|
| [`results/cell_density_estimate.csv`](results/cell_density_estimate.csv) | Density estimate, denominator and source plate. |
| [`results/mutation_frequencies.csv`](results/mutation_frequencies.csv) | Each comparison's treated/background plate and `relation` field. |

```bash
Rscript scripts/validate_repository.R
```

The final censored observation is marked `lower_bound`. Keep that qualifier
when using the table. Photographs remain the original evidence and are not
regenerated by these commands.

### 5. Troubleshooting and interpretation

| Symptom | Action |
|---|---|
| `Rscript` is not recognised | Add the R installation's `bin` folder to PATH, then open a new terminal. |
| An input file cannot be found | Return to the repository root; keep the checked-in folder structure. |
| A recalculated value differs from a rounded README value | Compare the full-precision CSV value before rounding. |
| You want to compare all treatments directly | Inspect the recorded control and denominator for each row; the assay conditions and count precision differ. |

This walkthrough reproduces calculations on the published observations. The
experimental background and limitations are described below.

## Reading mutation without sequencing

The WP2 assay starts with an *E. coli* strain that cannot grow without tryptophan. A reverse mutation restores the Trp⁺ phenotype, turning each colony on selective medium into a visible readout of mutagenesis.

| Untreated SA2 | UV 20 s | UV 40 s |
|---:|---:|---:|
| 14 colonies | 911 colonies | >1,000 colonies |

The visual jump is hard to miss: UV exposure produced the strongest reversion signal in this experiment.

| ![UV 20 seconds](figures/plate-11-uv-20s.jpg) | ![UV 40 seconds](figures/plate-12-uv-40s.jpg) |
|---|---|
| **20 s UV** | **40 s UV** |

## The MMS diffusion fingerprint

MMS tells a more spatial story. In a spot test, the chemical diffuses away from a central disc. Mutagenic stimulation and local toxicity can therefore appear on the same plate.

| 1% MMS | 2% MMS | Water control |
|---|---|---|
| ![1 percent MMS](figures/plate-07-mms-1pct.jpg) | ![2 percent MMS](figures/plate-08-mms-2pct.jpg) | ![Water control](figures/plate-09-water-control.jpg) |
| 46 colonies | 73 colonies | 11 colonies |

The 2% plate produced more revertants than the 1% plate, but the concentration gradient means these images are better for **qualitative dose-response interpretation** than exact mutation-frequency estimation.

## Quantitative snapshot

Plate 6 was used for the viable-cell estimate because its 276 colonies fell within the countable range. This gave an estimated starting density of **2.76 × 10⁹ CFU/mL** and approximately **2.76 × 10⁸ cells plated** on each undiluted assay plate.

| Comparison | Induced mutation frequency |
|---|---:|
| MMS liquid treatment | 3.62 × 10⁻⁹ |
| MMS spot, 1% | 1.16 × 10⁻⁷ |
| MMS spot, 2% | 2.14 × 10⁻⁷ |
| UV, 20 s | 3.25 × 10⁻⁶ |
| UV, 40 s | >3.57 × 10⁻⁶ |

These values are not perfectly interchangeable: MMS liquid treatment used SA1, whereas the UV plates used SA2, and the UV colonies were too dense for precise counting.
